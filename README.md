# DecoupledExam —— AI 教考分离在线考试系统

> 基于 **Spring MVC** 的在线考试平台，集成 **LLM 大模型自动阅卷**与**人脸识别 / 注意力监测**防作弊，实现题库管理、智能组卷、在线考试、自动评分的全流程。
>
> *An online exam platform (Spring MVC) integrating LLM auto-grading and face-recognition anti-cheating.*

## ✨ 功能特性 · Features

- **题库管理**：试题录入、分类与维护
- **智能组卷**：按规则自动组卷
- **在线考试**：限时答题、权限控制
- **LLM 自动阅卷**：大模型辅助主观题评分
- **防作弊**：人脸识别 + 注意力监测

## 🧱 技术栈 · Tech Stack

- Java · Spring MVC · Hibernate · LLM · 人脸识别

## 📌 方向 · Direction

本项目体现「后端工程 + 大模型应用落地」能力，是大模型应用方向（Agent/LLM 应用后端）的典型工程实践。
